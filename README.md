# ml5.jsで作る！はじめてのAIプログラミング

## このチュートリアルについて

このチュートリアルでは、JavaScriptのライブラリである `ml5.js` を使って、AIプログラミングの世界を探検します。難しい数式や環境構築は不要です。Webブラウザだけで、画像認識や物体検出といったAIの基本的な技術を体験できます。

さあ、一緒にAIプログラミングの第一歩を踏み出しましょう！
